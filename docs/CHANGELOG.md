# 更新日志 / Changelog

## v1.2.0 (2026-03-16)

### 新功能

- **全局快捷键唤醒窗口** — 支持自定义全局快捷键（默认 `Alt+H`），在后台按快捷键即可唤醒/显示窗口。可在设置中修改快捷键组合
- **工具菜单** — 工具栏重构为 Windows 风格菜单条，刷新 DNS / 备份管理 / 设置收纳到「工具」下拉菜单
- **保存提示** — `Ctrl+S` 保存后弹出成功/失败提示（Message toast）

### 优化

- **启动自动选中活跃分组** — 启动时默认选中当前激活的分组，不再默认选第一个
- **文本编辑器统一保存** — 文本模式移除编辑器内保存按钮，编辑内容自动同步到后端，统一通过顶部 `Ctrl+S` / 保存按钮写入系统 hosts 文件
- **工具栏布局** — 工具菜单靠左，重新加载/保存按钮靠右

### 修复

- **切换视图不再误触未保存提示** — 切换表格/文本视图时，编辑器加载内容不再被误判为用户编辑
- **分组拖拽排序修复** — 使用本地可变副本 + watch 同步模式，解决 SortableJS 直接修改 Pinia store 导致的拖拽异常

## v1.0.0 (2026-03-13)

### 首个版本

- 分组管理 — 将 hosts 条目按分组管理，每个分组独立存储为 `.hosts` 文件
- 单选激活 — 一次只激活一个分组，即时写入系统 hosts 文件
- 启动同步 — 启动时对比系统 hosts 与本地副本，外部修改会被保留
- 双视图编辑 — 表格视图与 CodeMirror 文本编辑器自由切换
- 拖拽排序 — 通过拖拽手柄调整分组和条目的顺序
- 搜索高亮 — 关键词过滤并高亮匹配内容
- 备份恢复 — 一键创建带时间戳的 hosts 备份，随时恢复
- 导入导出 — 粘贴文本导入，一键复制导出
- DNS 刷新 — 一键执行 `ipconfig /flushdns`
- 系统托盘 — 关闭窗口最小化到托盘，右键菜单快捷操作
- 暗色模式 — 浅色 / 深色 / 跟随系统
- 双语支持 — 中文 (zh-CN) 和英文 (en-US)
- 便携运行 — 配置和数据存储在程序目录下
- 全局快捷键 — `Ctrl+S` 保存、`Ctrl+R` 重新加载
